# GameBoard Undoの現在仕様

更新日: 2026-10-12

この文書は現在の作業ツリーの実装を記録する。`codex/fix-undo-outside-own-turn` の未マージ変更を含むため、公開済みアプリの仕様を保証するものではない。

## 通常の操作Undoを使える条件

オンラインでは、自分が行った取り消し可能な操作の履歴があれば、自分ターン・相手ターンのどちらでも自分側の既存Undoボタンを使用できる。相手ターン中に新しい操作を許可する変更ではない。攻撃宣言など既存のターン制限はそのまま維持する。

- 対戦中かつ既存の操作ロックが解除されていること。有効な自分の履歴があること。
- 相手側のボタンや観戦者からは操作できない。切断・再接続などで操作がロックされている場合も使用できない。
- 相手が盤面や数値を変更した後は、それ以前の自分の履歴へ戻せない。相手が自分の操作をUndoしても、失効した履歴は復活しない。
- ターン終了など、既存の履歴境界を越えるUndoはできない。自分の直前操作から複数回戻せるのは、有効な自分の履歴が続く間だけ。
- 通信の遅れでボタンを押す直前に履歴が失効しても、ホストの最新状態で判定し、拒否したUndoには完了ログ・通知を追加しない。
- 手札の確認など状態を変えないローカル表示操作は履歴を失効させない。
- ボタンの追加や画面の縦幅増加はない。ソロの履歴所有者によるボタン切り替えは継続する。

ターン終了Undoは別機能であり、既存の表示条件・確認ダイアログ・復元処理を変更しない。通常の操作Undoはターン終了Undoのバックアップを維持する。数値グループ、20件の操作履歴、100件のログ、非公開情報、通知対象も既存通り。

## ログと一時通知

取り消しに成功したとき、公開可能な要約を「最近のイベント」に追加する。一時通知の対象は、要約の種類がカード移動・ルック・シャッフルになった取り消しに限る。

| 取り消す操作 | ログ | 一時通知 | 表示内容 |
| --- | --- | --- | --- |
| プレイヤーの数値調整（ライフ・PP・最大PP・EP・SEP・コンボ） | あり | なし | 対象プレイヤーと、取り消し前 → 復元後の値。最大PPの変更に伴うPPの復元も含む |
| カードのATK・HP補正、汎用カウンター調整 | あり | なし | 補正／カウンターの種類と対象枚数。条件を満たす単一カードは名前と値も表示 |
| 複数枚の数値調整 | あり | なし | 調整した項目と対象枚数 |
| ゾーン間のカード移動 | あり | あり | 移動元・移動先・枚数。異なるプレイヤーのゾーン間なら双方を区別 |
| デッキからのサーチによる移動 | あり | あり | Undoによる逆向きの移動。手札へのサーチなら「手札 → 山札: 1枚」など |
| 複数枚のゾーン間移動 | あり | あり | 移動元・移動先ごとに集計した枚数 |
| ルックで確定した操作 | あり | あり | 元のルックで指定した移動先と枚数。「手札: 1枚、山札の下: 1枚」など |
| デッキのシャッフル | あり | あり | シャッフルを取り消した事実のみ |
| レスト／スタンド（タップ／アンタップ） | あり | なし | 向きの操作を取り消した事実 |
| 裏表・カード面の変更 | あり | なし | カード面の操作を取り消した事実 |
| トークン生成 | あり | なし | トークン生成を取り消した事実 |
| 攻撃宣言 | あり | なし | 攻撃を取り消した事実 |
| ターン終了 | あり | なし | ターン終了を取り消した事実 |
| 種類を安全に分類できない操作 | あり | なし | 「直前の操作を取り消しました」という汎用の要約 |

サーチ画面を開いただけでは取り消し対象は増えない。サーチ後のシャッフルは、実際に実行すれば移動とは別の取り消し対象になる。既存のシャッフル確認は継続する。

ルックは、手札・公開して手札・場・EX・墓場・山札の上・山札の下への指定をまとめて1回のUndoで復元する。公開して手札に加えた枚数も「手札」に集計する。山札内の順番だけを変えたルックも、要約がルックであれば通知対象になる。

## 通知が出ない例外

「カード移動すべてに通知」ではなく、現在は分類できた要約を基準にしている。

- 同じゾーン内の並べ替えやリンクの変更など、前後でどのカードのゾーンも変わらない移動操作は、汎用ログのみになる。
- 変更前に保存された履歴など、操作の種類を記録していない履歴も、汎用ログのみになる。
- 未知のゾーンや、保存された操作の説明と復元内容の不一致で詳しい要約を作れない場合も、汎用ログのみになる。

これらの例外でも、Undoによる状態の復元は行われる。詳細な移動通知を増やす場合は別途仕様とテストを追加する。

## UIの挙動

- 一時通知は既存の画面上部の通知領域に約3.2秒表示し、自動で消す。
- 確認・閉じる操作は不要。固定表示でレイアウトの縦幅を増やさず、ポインター操作を遮らない。
- 通知とログには同じ要約を使う。一時通知は既存のカード操作通知と領域を共有し、新しい通知が出ると置き換わる。
- 数値調整などログのみのUndoは、表示中の他の操作の通知を上書きしない。その通知は元のタイマーで消える。
- 元の操作のログは削除・書き換えず、Undoログを新しい項目として追加する。ログは最新100件まで保持するため、追加により古い項目が押し出されることはある。
- 件数を増やしても既存のドロップダウンは高さを固定し、スクロールで古いログを確認する。100件は実用的な保持上限であり、全端末で測定した絶対的な最大値ではない。
- 「最近のイベント」の表示は対戦中のみ。ログは永続的な監査履歴ではない。
- ターン終了Undoの既存の確認ダイアログは継続する。今回の成功通知とは別のUIである。

## 非公開情報の扱い

- 移動のUndoは、カード名を出さずゾーンと枚数で表す。カードID・画像・デッキ内の位置・順番は要約に含めない。
- ルックは指定先と枚数だけを表示する。元の操作でカードを公開していても、Undoによってカード名を再表示したり公開ダイアログを開いたりしない。
- シャッフルは取り消した事実だけを表示する。
- 数値調整でカード名と値を表示できるのは、対象が1枚で、Undo前後の両方で表向きかつ場・EX・墓場・除外のいずれかにある場合だけ。
- 手札・メインデッキ・エボルヴデッキ、裏向きのカード、複数枚調整では、カード名や各カードの数値を出さず項目と枚数にする。
- プレイヤー数値は実際の復元前後の値を表示する。カードのATK・HPは最終能力値ではなく、記録されている補正値として明示する。
- オンラインの両プレイヤー・観戦者に同じ基準の要約を共有する。「あなた／相手」などの呼称は閲覧者に合わせ、ソロ・観戦ではプレイヤー番号を使う。

この保護は新しいUndo要約・ログ・通知についてのもの。既存の同期スナップショットには非公開カード情報が含まれており、通信データ全体からの秘匿は今回の変更範囲に含まれない。

## Undoの単位と既存動作

- 同じ操作主体が、同じプレイヤー／カードの同じ数値項目を連続して調整した場合、増減の方向にかかわらず1回のUndoにまとめる。例: ライフを+3して-1すると、Undoで調整前の値へ戻る。
- カードAのATKとカードBのATK、同じカードのATKとHPは別の操作。単一カード操作と複数枚指定操作も別の単位になる。
- 複数枚の数値調整は、対象集合とカード構成が同じ場合にまとめる。選択順や増減方向だけでは分割しない。
- 他の操作、相手の操作、対象／カード構成の変更、再接続などで数値グループの継続条件を満たさなくなれば別のUndoになる。時間だけで区切る仕様はない。
- 調整前と同じ状態に戻った数値グループは取り消し履歴から除く。ただし、最大PP変更でPPだけが変わった場合など、復元すべき差分が残れば履歴を残す。
- 操作Undoの履歴上限は20件。複数枚操作はまとめて復元する。リンク・エボルヴの関係、山札順なども元のチェックポイントに従って復元する。
- ターン終了Undoは操作Undoとは別のバックアップを使う。操作Undoはターン終了Undoのバックアップを消したり復活させたりしない。
- 有効な保存履歴は再開後も利用できる。操作説明は許可した項目だけ復元し、数値グループは再開後の操作へ継続しない。

ログ・通知の追加は復元内容、Undo可能なタイミング、操作権限、数値のまとめ方を拡張する変更ではない。ソロでは両側の操作履歴を扱い、オンラインでは相手の操作で従来の自分の操作履歴を継続しない。

## 成功・失敗とオンライン共有

Undoで状態が実際に復元され、リビジョンが進んだ場合だけ新しいログ／通知を生成する。履歴なし、権限違反、拒否された操作では生成しない。

オンラインではホストが復元結果と`UNDO_COMPLETED`の要約を同じスナップショットに含めて送る。受信したUndoを含むスナップショットは、既に処理したUndoのリビジョン以下ならUndo表示を重複させない。保留中の別々のUndoが1つのスナップショットにまとまった場合は各ログを追加し、一時通知には最後の通知対象が表示される。
