# バージョンとリリース運用

## 画面表示とデプロイ

Home のフッターは `1.1.0 (74e05d3)` のように表示します。

- リリース番号の正は `package.json` の `version` です。`package-lock.json` のルート番号も揃えます。
- ビルド識別子は `VERCEL_GIT_COMMIT_SHA` の先頭7文字です。値がない・不正な場合はローカルの Git HEAD を使います。
- Git 情報が取得できないソースアーカイブなどでは `unknown` と表示します。ビルドは続行します。
- `APP_VERSION` と Git タグは表示の決定に使いません。
- 識別子はビルド時に確定します。新コミットのデプロイで変わり、同じコミットの再デプロイでは変わりません。
- ローカルの未コミット変更は識別子に反映されません。

Vercel では `Automatically expose System Environment Variables` を有効にします。
以前の `APP_VERSION` は削除して構いません。Preview で表示の7文字とデプロイ対象コミットが一致することを確認してください。
システム変数の説明: https://vercel.com/docs/environment-variables/system-environment-variables

## タグ

タグは正式リリースのコードを示す注釈付きタグ `vX.Y.Z` として残します。
通常の修正・カード更新ごとにタグを作る必要はありません。リリース間のコードはビルド識別子で区別します。
既存のタグを移動・上書きしません。タグ追加だけでは配信中の表示は変わりません。

1. リリースの変更内容に合わせて番号を決めます。機能追加は minor、修正は patch、互換性を壊す変更は major を基本にします。
2. 専用ブランチで package / lockfile のルート番号を同時に更新します。
3. lint・アプリ型チェック・全テスト・build と、影響する E2E を実行します。
4. PR を main にマージします。
5. main のリリース対象コミットを確認し、package の番号に一致する注釈付きタグを作成・push します。
6. GitHub のリリースノートに主な変更と互換性上の注意を記載します。
7. Vercel のデプロイ対象コミットと Home 表示を確認します。

今回の導入は `v1.1.0` のリリースに含め、package / lockfile の番号を `1.1.0` に揃えています。
過去のタグは付け替えません。
自動採番・自動タグ作成は導入していません。

## 保存した対戦の互換性

保存先は現在と同じ `sessionStorage` です。同じタブ内の復元を対象にします。

- 新規保存には `sessionSchemaVersion: 1` を付けます。`appVersion` は保存元のリリース番号として記録し、互換性判定には使いません。
- 対応する形式番号なら、リリース番号・ビルド識別子が変わっても既存の状態検証・正規化を通して復元します。
- 未対応の形式番号・不正な保存データは復元しません。現在の起動処理はそれらを削除します。
- 保存形式や値の意味を互換性なく変更する場合は `SESSION_SCHEMA_VERSION` を上げ、必要なら明示的な移行処理を追加します。
- 形式番号のない旧データは、保存元が既知の旧リリース `1.0.1`、または現在のリリース番号と一致する場合だけ schema 1 として移行します。先頭の `v` は無視し、状態の検証・既存の正規化も実行します。
- 旧 `v1.0.1` / `1.0.1` の移行対象は、今回の `1.1.0` への採番後も維持します。旧 `1.0.0` や独自の `APP_VERSION` で保存したデータは移行しません。

新しい保存キーは `sv-evolve:host-session:versioned:<room>` です。このキーは将来の形式変更でも維持します。
新しい保存が存在する場合は、読めなくても旧キーへフォールバックしません。
旧キーは新キーが存在しない場合だけ読み、復元後の保存・破棄・無効データの削除時に除去します。
新規保存が失敗した場合も、古い復元地点が残らないよう旧キーを削除します。

形式番号導入前のアプリへ戻すと、新しいキーは読めないため新形式の対戦は復元できません。
形式番号導入後のアプリ同士では、対応する番号のものだけ復元します。
この互換性管理は保存データ用です。異なるビルド間の P2P 通信互換性を保証するものではありません。
