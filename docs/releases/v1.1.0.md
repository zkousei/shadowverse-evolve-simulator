# v1.1.0

v1.0.1 以降の機能追加と改善をまとめたリリースです。

## 主な変更

- モバイル・タブレット向けのレイアウト、タッチ操作、対戦表示モードを追加しました。
- 複数カードの選択と一括操作、複数段階の Undo、操作ログとキーボードショートカットを改善しました。
- カードカタログを生成データから段階的に取得する構成へ変更し、初期読み込み、同時取得数の制御、取得失敗時の再試行を改善しました。
- デッキ構築画面の数量ボタン・ページ切り替えと、先攻後攻に応じたターン数・Undo の不具合を修正しました。
- CP05 の公開済みプレビューカードを更新しました。
- Home にリリース番号とコミット SHA を表示します。新しいコミットのデプロイで識別子が自動更新され、Vercel の `APP_VERSION` の手動更新は不要になります。
- 保存した対戦の互換性判定を表示バージョンから分離し、保存形式番号で管理します。

## 保存した対戦について

- 新しい保存形式では、対応する形式番号の間はリリース番号が変わっても復元できます。
- 形式番号のない旧データは、旧 `v1.0.1` / `1.0.1`、または現在の `v1.1.0` / `1.1.0` の保存を対象に、状態の検証・正規化後に移行します。
- 旧 `1.0.0` やそれ以外の独自 `APP_VERSION` の保存データは移行対象外です。非対応・不正な保存データは起動時に削除されます。
- 形式番号導入前のアプリへ戻した場合、新形式で保存した対戦は復元できません。
- 保存先は引き続き `sessionStorage` です。ブラウザ終了後の永続保存や、異なるビルド間の P2P 通信互換性を保証する変更ではありません。

## デプロイ設定

- `APP_VERSION` は表示の決定に使用しません。以前の値が残っていても表示は固定されません。
- Vercel のシステム環境変数公開設定を有効にし、`VERCEL_GIT_COMMIT_SHA` がビルド時に取得できることを確認してください。
- 同じコミットの再デプロイでは識別子は変わりません。
- 詳細は [リリース運用](https://github.com/zkousei/shadowverse-evolve-simulator/blob/v1.1.0/docs/release-management.md) を参照してください。
