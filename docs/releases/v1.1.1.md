# v1.1.1

旧形式の対戦保存データの移行処理を削除し、新形式の保存データを保護する処理を整理しました。

## 変更内容

- `sessionSchemaVersion` のない旧形式の対戦データは復元しません。部屋をホストとして開いた際、その部屋の旧保存キーだけを削除します。
- v1.1.0 から使用している `sessionSchemaVersion: 1` の保存・復元・破棄は維持します。アプリのリリース番号が 1.1.1 に変わっても、対応する形式の対戦は復元できます。
- 特殊な部屋 ID によって旧保存キーが他の部屋の新保存キーと重なる場合、そのキーを削除しないよう保護しました。
- 旧保存キーの削除に失敗しても、新形式の保存・復元を妨げないようにしました。
- 新形式内の Undo 履歴と省略可能フィールドの正規化は維持しています。

## 注意点

旧形式で保存された対戦は再開できなくなります。保存デッキや他の部屋の保存データは変更しません。
保存先は引き続き `sessionStorage` です。対戦ルール・カード操作・P2P 通信仕様の変更はありません。
