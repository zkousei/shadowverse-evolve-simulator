# 配信用カードカタログの保持履歴

このディレクトリはビルドキャッシュではなく、公開済みバージョンを残すためのGit管理対象です。
正本は引き続き `public/cards_detailed.json` と `public/cards_preview.json` です。

- `versions.json`: 保持するバージョンの台帳。記録済みファイルの欠損をビルドで検出します。
- `<catalogVersion>.json.gz`: 統合後の全カードを完全に保持した圧縮スナップショット。
  ファイル名は生成物の内容から決まります。手で編集・上書き・削除しません。

正本のカードデータを更新したら、次を実行し、正本・追加されたアーカイブ・台帳を一緒にコミットします。

```sh
npm run cards:audit:all
npm run cards:retain:catalog
npm run build
```

同じ配信データでの再実行は既存アーカイブを変更しません。
既存バージョンの破損は修復せずエラーにします。履歴への同時書込は拒否します。
強制終了で `.history-lock` が残った場合は、実行中プロセスがないこととファイルを調査してから対処します。

ビルドは記録済み全版を検証し、各 `versions/<catalogVersion>/` を配信対象にします。
ルートのmanifestは現在の正本だけを指します。未記録の正本、欠損・破損・余分な履歴はビルド失敗です。
履歴を消すと、開いたままの画面が旧詳細を取得できなくなる可能性があります。
この段階では期限・件数による自動削除を設けません。台帳からの削除も通常更新の対象外です。

保管量・ビルド時の処理量・配信物の容量はバージョン数に応じて増加します。
ブラウザーは必要な版・ファイルだけを取得します。
履歴が大きくなる場合は、保持期限と利用中セッションの終了処理、または永続ストレージへの移行を
別の変更として設計・検証してから見直します。ビルド時に公開サイトから旧版を取り込む処理はありません。
